# 我的课表

一个**本地网页版课表应用**：手机/电脑浏览器都能用，可"添加到主屏幕"像 App 一样全屏运行。数据只存在你自己的浏览器里，**不需要账号密码、没有服务器、不上传任何数据**。

已预置 **广东工业大学 2026 秋季学期**（信息工程专业）的真实课表，开学日期 2026-08-31。

## 功能

- **今日页**：今天要上的课、当前/下一节课高亮、上课倒计时
- **课表页**：整周网格（周一~周日 × 12 节），左右翻周，非本周的课灰显，单双周/跳周精确显示
- **自动周次**：根据开学日期自动算"今天是第几周"
- **课程管理**：手动添加/编辑/删除课程与班会等活动；点课表空白格可快速添加
- **教务导入**：把教务系统课表页面另存为 HTML 后导入，自动识别（换学期用）
- **数据备份**：导出/导入 JSON 文件，换设备不丢
- **离线可用**：PWA 缓存，断网也能看

## 使用方式（三选一或组合）

| 方式 | 适合 | 说明 |
|---|---|---|
| **桌面单文件** | 电脑 | 双击 `我的课表.html` 即可在浏览器打开（桌面有副本）。不需要 Node、不需要联网；数据存在浏览器里 |
| **部署到线上** | 手机 + 电脑 | 见下节「部署到线上」，手机"添加到主屏幕"后像 App 一样离线随时用 |
| **开发模式** | 开发调试 | `npm run dev`，手机电脑同一 WiFi 访问 Network 地址 |

### 手机上使用

- **部署到线上后（推荐）**：手机浏览器打开网址 → Android Chrome 菜单「添加到主屏幕」/ iOS Safari 分享「添加到主屏幕」→ 之后点图标全屏使用，**离线可用**（不依赖电脑开机）
- **局域网临时用**：手机与电脑连同一 WiFi，打开 `npm run dev` 显示的 Network 地址（电脑需保持运行）

### 重新生成桌面单文件版

改了代码后运行 `npm run build:single`，会重新生成 `我的课表.html` 并自动复制到桌面。

> 注意：不同方式（单文件 / 线上网址 / localhost）属于不同的浏览器源，数据互相独立。换方式用的时候用「设置 → 数据备份」导出 JSON 再导入即可迁移。

### 长期使用（可选）

`npm run build` 后把 `dist/` 部署到任意静态托管（GitHub Pages、Vercel 等）。

## 部署到线上（让手机随时打开）

以 GitHub Pages 为例：
1. 注册/登录 GitHub，新建一个仓库（如 `myclass`）
2. 推送本项目，仓库 Settings → Pages → 选择 GitHub Actions 或 gh-pages 分支
3. 得到 `https://<用户名>.github.io/myclass/` 网址，手机打开并添加到主屏幕

## 换学期导入课表

1. 电脑浏览器登录教务系统（jxfw.gdut.edu.cn）→ 信息查询 → 课表查询，选好学期
2. 按 `Ctrl+S` 保存网页（保存类型选「网页，全部」）
3. 应用 → 设置 → 从教务系统导入课表 → 选择保存的 HTML 文件（可连同 `xxx_files` 文件夹里的 HTML 一起多选；也可以在课表页面全选复制后粘贴）
4. 核对识别预览 → 确认导入（只替换教务课程，手动加的自定义事项保留）

> 也可以导入后在本应用「设置 → 数据备份」导出 JSON，发给同学导入即可分享课表。

## 技术栈

Vue 3 + TypeScript + Vite + vite-plugin-pwa，数据存 localStorage。
课表解析：优先提取教务页面内嵌的 `kbxx` 结构化 JSON，失败时解析课表表格兜底。

## 调试

URL 加 `?today=2026-09-03&now=08:40` 可固定模拟某个时刻，验证"进行中/倒计时"等状态。

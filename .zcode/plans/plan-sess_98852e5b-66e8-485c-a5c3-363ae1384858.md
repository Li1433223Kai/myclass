# 课表快速查询 App — 最终实施计划（广工版·已拿到真实数据）

## 已完成的准备

从你保存的 `教学管理系统.html` 中已成功提取：
- **2026秋季完整课表**：10 门课（名称/节次/星期/周次/地点/老师），外加 1 门集中实训「电子线路CAD设计」（2周，具体周次未知，之后在 App 里手动补）
- 学校系统节次编号与你描述的作息**完全吻合**（共 12 节，第 5 节 = 中午节 13:50–14:35）
- 导入方案确定：广工教务页面内嵌结构化 JSON（kbxx 字段），直接读取，可靠性高；表格解析做兜底

## 你能得到什么

网页 App（手机/电脑浏览器可用，可"添加到主屏幕"全屏运行），**首次打开自动载入你的真实课表**，明天开学即用：
- **今日页**：今天的课程时间轴，高亮当前/下一节课、教室、"还有几分钟上课"倒计时
- **整周课表**：周一~周日 × 12 节格子视图，每门课一个色块（含节次时间），左右切换周次，非本周课置灰
- **自动周次/单双周**：开学日预填 2026-08-31（第 1 周周一），周次自动算，"1,3-9"这类跳周精确显示
- **手动增删改**：补电子线路CAD设计的周次、加班会/活动、应对调课
- **换学期导入**：以后（如 2027 春季）打开教务课表页 Ctrl+S 存 HTML，拖进 App 自动识别（解析预览确认后写入）
- **数据备份**：JSON 导出/导入，换设备不丢
- **离线可用**：数据只存本机，无服务器、无上传、不需要学号密码

**本期不做**（需原生 App）：上课通知提醒、桌面小组件、考试/成绩查询。

## 技术方案

- Vue 3 + TypeScript + Vite，vite-plugin-pwa（图标/离线缓存/可安装），localStorage 存储
- 课程模型：名称/编号/老师 + 多个时段（星期、起止节次、周次列表、地点）——一个课多个上课时段各存各的
- 解析器：优先提取教务页面内嵌 JSON，兜底解析课表网格 HTML；解析结果先预览确认再写入
- 默认节次时间表（可在设置页改）：
  1节 8:30–9:15 / 2节 9:20–10:05 / 3节 10:25–11:10 / 4节 11:15–12:00 / 5节 13:50–14:35（中午）/ 6节 14:40–15:25 / 7节 15:30–16:15 / 8节 16:35–17:20 / 9节 17:25–18:10 / 10节 18:30–19:15 / 11节 19:20–20:05 / 12节 20:10–20:55

1. 检查 Node.js 环境（≥18，缺则给安装指引），初始化项目
2. 数据模型 + 本地存储 + 内置你的 2026 秋季课表种子数据

5. 今日页：时间轴、当前/下节课高亮倒计时

7. JSON 导出/导入备份
8. PWA 图标与离线缓存，浏览器全功能实测（用真实课表数据核对每一门课的显示）
